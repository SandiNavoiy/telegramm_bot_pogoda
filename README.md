# 🌤 Умный Telegram-бот прогноза погоды

Универсальный асинхронный Telegram-бот на **Python 3** (фреймворк `aiogram 3.x`), который предоставляет актуальную информацию о погоде, ежедневный утренний прогноз, а также дневное предупреждение о дожде или снегопаде во второй половине дня.

## ✨ Возможности

- 🏙 **Выбор и смена населенного пункта**:
  - Указание города текстом (например: `Москва`, `Санкт-Петербург`, `Казань`, `Ташкент`).
  - Указание города отправкой геолокации нажатием одной кнопки в Telegram (бот автоматически определяет город по координатам).
  - Смена города в любое время через меню `🏙 Сменить город` или команду `/city`.
- 🌅 **Утренний прогноз (07:00)**:
  - Автоматическая рассылка сводки на текущий день: общая погода, диапазон температур (мин/макс), вероятность осадков и срез утро/день/вечер.
- ⚠️ **Дневная проверка осадков (14:00)**:
  - В 14:00 бот анализирует почасовой прогноз на остаток дня (с 14:00 до 23:59).
  - Если прогнозируется **дождь, ливень, мокрый снег, снегопад или гроза**, бот отправляет персональное предупреждение с указанием точного времени и напоминанием взять зонт или одеться теплее.
  - Если день ясный и осадков не ожидается, бот не беспокоит лишними сообщениями.
- 🌤 **Ручной запрос погоды**:
  - Кнопка `🌤 Погода сейчас` / команда `/weather` — моментальный срез текущей погоды (температура, ощущение, влажность, давление в мм рт. ст., скорость ветра).
  - Кнопка `📅 Прогноз на день` / команда `/forecast` — подробный прогноз на день.
- ⚙️ **Гибкие настройки**:
  - Возможность для каждого пользователя индивидуально включать/выключать утреннюю рассылку и дневные предупреждения.
- 💾 **Надежная база данных**:
  - Хранение пользователей и настроек в SQLite с использованием асинхронного драйвера `aiosqlite`.
- 🌐 **Два погодных провайдера**:
  - Поддержка **OpenWeatherMap API**.
  - Встроенный бесплатный фоллбек на **Open-Meteo API** (работает сразу «из коробки» без необходимости регистрироваться и получать API-ключи).

## 🛠 Стек технологий

- **Язык**: Python 3.10+
- **Telegram Bot API**: [aiogram 3.x](https://docs.aiogram.dev/)
- **Асинхронные HTTP запросы**: [aiohttp](https://docs.aiohttp.org/)
- **Планировщик задач**: [APScheduler 3.x](https://apscheduler.readthedocs.io/)
- **База данных**: [aiosqlite](https://aiosqlite.omnilib.dev/) (SQLite)
- **Управление окружением**: `python-dotenv`
- **Работа со временем**: `pytz`

## 🚀 Быстрый старт

### 1. Клонирование и подготовка окружения

Перейдите в папку с проектом:
```bash
cd d:\python\telegramm_bot_pogoda
```

Создайте и активируйте виртуальное окружение:

**Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS (Bash):**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

---

### 2. Получение токена Telegram бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите отображаемое имя для вашего бота (например, `Погода Информер`).
4. Укажите уникальный юзернейм (например, `my_super_weather_bot`).
5. Скопируйте полученный **API токен** вида `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`.

---

### 3. Получение ключа OpenWeatherMap (опционально)

> 💡 **Примечание:** Если вы не хотите регистрироваться на OpenWeatherMap, **пропустите этот шаг**. Бот автоматически использует бесплатный провайдер **Open-Meteo**, не требующий ключей.

Если хотите использовать OpenWeatherMap:
1. Зарегистрируйтесь на сайте [openweathermap.org](https://openweathermap.org/).
2. Перейдите в раздел [API Keys](https://home.openweathermap.org/api_keys).
3. Создайте новый бесплатный ключ и скопируйте его.

---

### 4. Настройка файла .env

Создайте файл `.env` в корневой папке проекта на основе `.env.example`:

**Windows:**
```powershell
copy .env.example .env
```

**Linux / macOS:**
```bash
cp .env.example .env
```

Откройте файл `.env` в любом текстовом редакторе и заполните параметры:

```env
# Обязательно: Токен вашего Telegram бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Опционально: Ключ OpenWeatherMap (оставьте пустым для Open-Meteo)
OPENWEATHER_API_KEY=

# Часовой пояс расписаний (например: Europe/Moscow, Asia/Yekaterinburg, Asia/Almaty)
TIMEZONE=Europe/Moscow

# Время отправки утреннего прогноза (часы и минуты)
MORNING_NOTIFICATION_HOUR=7
MORNING_NOTIFICATION_MINUTE=0

# Время дневной проверки осадков (часы и минуты)
AFTERNOON_CHECK_HOUR=14
AFTERNOON_CHECK_MINUTE=0

# Путь к файлу базы данных SQLite
DATABASE_PATH=weather_bot.db
```

---

### 5. Запуск бота

Запустите бота командой:
```bash
python main.py
```

При успешном запуске в консоли появится лог:
```text

2026-10-05 14:20:01 [INFO] WeatherBot: Планировщик запущен. Часовой пояс: Europe/Moscow. Утренний прогноз: 07:00, Дневная проверка осадков: 14:00.
2026-10-05 14:20:01 [INFO] WeatherBot: Бот успешно запущен и ожидает сообщений...
```

## 🤖 Команды и использование

### Команды в чате:
- `/start` — начало работы с ботом, запрос города или приветствие.
- `/weather` — мгновенный запрос текущей погоды.
- `/forecast` — подробный прогноз на день.
- `/city` — изменение населенного пункта.
- `/settings` — управление включением/отключением рассылок.
- `/help` — подробная справка по функционалу.

### Кнопки клавиатуры:
- `🌤 Погода сейчас` — текущая температура, давление, влажность, ветер.
- `📅 Прогноз на день` — сводка на день с разбивкой утро/день/вечер.
- `🏙 Сменить город` — запускает ввод нового города или отправку координат.
- `⚙️ Настройки` — интерактивные кнопки для включения/выключения уведомлений в 07:00 и 14:00.

## 🖥 Развертывание на Linux сервере (systemd)

Для бесперебойной работы 24/7 на VPS/VDS сервере под управлением Ubuntu/Debian:

1. Создайте юнит-файл службы:
```bash
sudo nano /etc/systemd/system/weather_bot.service
```

2. Вставьте следующую конфигурацию (замените пути и пользователя на свои):
```ini
[Unit]
Description=Telegram Weather Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/telegramm_bot_pogoda
ExecStart=/home/ubuntu/telegramm_bot_pogoda/.venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

3. Активируйте и запустите службу:
```bash
sudo systemctl daemon-reload
sudo systemctl enable weather_bot
sudo systemctl start weather_bot
```

4. Проверка статуса:
```bash
sudo systemctl status weather_bot
```
